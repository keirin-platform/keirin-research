# 研究の取り決め

オーナーが決めた約束。`適用範囲` に書いた作業では、必ず守る。

## COMMIT-001 予想は確率で出す

- 内容: 予想は、各選手の1着・2着以内・3着以内の確率で出す。車券の買い目や回収率では出さない。
  確率の良し悪しは、対数損失・ブライアスコア・較正（予測した確率と実際の割合の一致）で測る。
- 種別: 取り決め
- 根拠: オーナーの指定
- 成立期間: 2026-10-05 から
- 出典: オーナー（2026-10-05 の会話）、keirin-platform:CLAUDE.md@0850049 オーナーの要望 8.
- 最終確認日: 2026-11-01
- 依存: なし
- 適用範囲: 予想を扱うすべての作業（keirin-platform の予想、記事、これから作るリポジトリ）

## COMMIT-002 登録・否定・保留の基準

- 内容: 広く知られている法則を、自分たちのデータで確かめてから知識（LAW）として登録する。データが足りず判断がつかないものは、保留にして `candidates.md` に置く。
  - 確認済み: 効果の 95% 区間（レースを単位にしたブートストラップ 2,000 回、seed 0）が0を含まず、かつ期間を日付で前半と後半に分けても点推定が同じ向き。同じデータで通説を次々に確かめるので、偶然の当たりを減らすために前半と後半の再現を求める。
  - 否定: 区間が ±実質的な大きさの内側に収まる（効果がないか、あっても実用上は無視できる）。または通説と逆の向きで確認済みの基準を満たす。否定も知識として登録する。
  - どちらでもなければ保留。
  実質的な大きさは測る前に決めて、法則の `検証の記録` に書く。v1 で決めた値は、ラインの連動が1レースあたり 0.05 組、1番車の勝率の差が 0.03（3ポイント）。
- 種別: 取り決め
- 根拠: オーナーの決定（登録と保留）と、設計書の基準
- 成立期間: 2026-11-01 から
- 出典: オーナー（2026-11-01 の会話）、keirin-platform:docs/superpowers/specs/2026-11-01-keirin-research-design.md@886fcb7 §7.3
- 最終確認日: 2026-11-01
- 依存: なし
- 適用範囲: keirin-research への登録

## COMMIT-003 封印期間を設けず、確かめ直す

- 内容: 最終確認のためだけに誰も見ずに残す期間（封印期間）は設けない。
  代わりに、登録のあとに入ってきたデータ（登録の時点では誰も見ていない）で法則を確かめ直す。時期は、期替わりのあと（4月・10月の下旬）と、本物の並びが1年分そろったとき。
  確かめ直して基準を満たさなくなったら候補に戻し、`python3 tools/kb.py dependents <ID>` で依存する知識を洗い出す。
- 種別: 取り決め
- 根拠: オーナーの決定
- 成立期間: 2026-11-01 から
- 出典: オーナー（2026-11-01 の会話）、keirin-platform:docs/superpowers/specs/2026-11-01-keirin-research-design.md@886fcb7 §7.3
- 最終確認日: 2026-11-01
- 依存: COMMIT-002
- 適用範囲: keirin-research への登録と見直し

## COMMIT-004 公開してよいもの

- 内容: keirin-research は Public。置いてよいのは、自分たちで集計した統計（件数、割合、検定の結果）と、データのスキーマ（表、列の意味、空の値の意味、期間）。
  置かないもの: 収集データとその抜き出し、選手名、選手登録番号、レースと位置から選手を特定できる記述、ビューアの URL、keirin.jp の内部 API の呼び出し方、オッズパークの並び予想や短評の文言。
  個別のレースを例に出すときは最小限にして、出典「KEIRIN.JP」を書く。オーナーの観察記録は Private の keirin-data に置く。
- 種別: 取り決め
- 根拠: KEIRIN.JP とオッズパークのサイトポリシー、オーナーの決定
- 成立期間: 2026-11-01 から
- 出典: オーナー（2026-11-01 の会話）、keirin-platform:docs/superpowers/specs/2026-11-01-keirin-research-design.md@886fcb7 §6
- 最終確認日: 2026-11-01
- 依存: なし
- 適用範囲: keirin-research に書くものすべて（知識、候補、スキル、評価ケース）

## COMMIT-005 個人差は有無だけ
