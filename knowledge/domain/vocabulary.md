# 用語と避ける言い方

競輪の言い方と、使わない言い方。答えや知識を書く前に確かめる。
オーナーはオートレースのプロジェクトも並行して進めているので、オートレースの言葉（号車、試走、ハンデ）が混ざりやすい。競馬の言葉も使わない。
`避ける言い方` に挙げた語は、知識（このファイルと README を除く）・候補・スキルに書くと `kb.py check` の誤りになる。

## TERM-001 競輪の数え方と車番

- 内容: 選手の車の番号は「車番」「1番車」と言う。レースの人数は「9車立て」「7車立て」、着差は「車身」。
  オートレースの「号車」「試走」「ハンデ」や、競馬の「騎手」「頭（何頭立て）」「馬券」「馬場」「斤量」「馬身」は使わない。車券は「車券」。
- 種別: 用語
- 根拠: 競輪の言い方
- 成立期間: 期間の制約なし
- 出典: keirin-platform:docs/superpowers/specs/2026-11-01-keirin-research-design.md@886fcb7 §5
- 最終確認日: 2026-11-01
- 依存: なし
- 避ける言い方: 号車、試走、ハンデ、騎手、/[0-9０-９一二三四五六七八九]頭/、頭立て、出走馬、馬券、馬場、斤量、馬身

## TERM-002 勝率・2連対率・3連対率

- 内容: 勝率は1着の割合、2連対率は2着以内の割合、3連対率は3着以内の割合。「連対」は2着以内のこと。
  出走表の勝率・2連対率・3連対率（`win_rate`・`top2_rate`・`top3_rate`）は直近4ヶ月の成績による値で、自分で期間を決めて数えた率とは一致しない。
- 種別: 用語
- 根拠: KEIRIN.JP の出走表の見方
- 成立期間: 期間の制約なし
- 出典: https://keirin.jp/pc/static/beginner/basics/racecard.html 出走表を見る、keirin-platform:docs/data-schema.md@0850049 entries
- 最終確認日: 2026-11-01
- 依存: なし
- 避ける言い方: なし

## TERM-003 並び・脚質・戦法

- 内容: 並びはラインの構成（誰がどのラインのどの位置に付くか）で、レース前の予想。表記は `2(13)56/74` のように、ラインを `/` で区切り、競りを括弧でくくる。
  脚質は KEIRIN.JP の出走表の分類で、逃（逃げ）・両（両方）・追（追込み）の3つ。
  オッズパークの並びに付く戦法（逃捲・追込・自在など）は別の分類で、脚質とは対応しない。
  決まり手（逃げ・捲り・差し・マーク）は、そのレースで1・2着の選手がどう決めたか（RULE-007）。脚質・戦法・決まり手を取り違えない。
- 種別: 用語
- 根拠: 取得元ごとの表記
- 成立期間: 期間の制約なし
- 出典: keirin-platform:docs/lines.md@0850049 オッズパークの形式、https://keirin.jp/pc/static/beginner/basics/racecard.html 出走表を見る
- 最終確認日: 2026-11-01
- 依存: なし
- 避ける言い方: なし
