# ファンの言葉とデータの項目の対応表

ファンが使う言葉が、データのどの項目に当たり、その項目が何を測っていて、何を区別できないか。指標や特徴を作るときに引く。
`照合` は、項目の意味を映像や公式の定義と突き合わせたかどうか。

## FIELD-001 先行

- 内容: ファンの言う「先行」（レースの先頭を走って主導権を取る）に近い項目は3つあり、どれも少しずつ違うものを測っている。
- 種別: データで確かめた事実
- 根拠: 項目の定義（RULE-007）
- 成立期間: 期間の制約なし
- 出典: keirin-platform:docs/data-schema.md@0850049 entries、https://keirin.jp/pc/static/beginner/basics/racecard.html 出走表を見る
- 最終確認日: 2026-11-01
- 依存: RULE-007
- ファンの言葉: 先行、逃げ、主導権を取る
- 項目: entries の `style`（脚質。逃）、`kimarite`（逃げ）、`bh`（H）。出走表の回数 `nige`・`home`
- 測っているもの: `style` は出走表の脚質の分類（その選手の得意な戦法）。`kimarite` の逃げは、そのレースで逃げて1・2着になったこと。H は残り1周の時点でホームを先頭で通過したこと
- 区別できないこと: 逃げて3着以下に沈んだ選手（決まり手が付かない）。H を取ったあと残り1周より後で捲られたかどうか。脚質が逃でも、そのレースで先行したかどうか
- 照合: 未照合

## FIELD-002 番手

- 内容: ファンの言う「番手」（先頭の直後の位置）は、lines 表のライン内の位置で表す。
- 種別: データで確かめた事実
- 根拠: lines 表の定義
- 成立期間: 本物の並びは 2026-10-05 以降（DATA-KD-003）
- 出典: keirin-platform:docs/data-schema.md@0850049 lines
- 最終確認日: 2026-11-01
- 依存: DATA-KD-003
- ファンの言葉: 番手、2番手、番手を回る
- 項目: lines の `line_pos`＝2（`line_size` が 2 以上）。競りは `contested`
- 測っているもの: レース前の予想の並びでの位置
- 区別できないこと: 実際のレースでその位置を回ったか（予想と実際がずれることがある）。競りの勝ち負け
- 照合: 未照合

## FIELD-003 捲り

- 内容: ファンの言う「捲り」（後方から一気に追い抜く）に近い項目。
- 種別: データで確かめた事実
- 根拠: 項目の定義（RULE-007）
- 成立期間: 期間の制約なし
- 出典: keirin-platform:docs/data-schema.md@0850049 entries、https://keirin.jp/pc/static/beginner/basics/racecard.html 出走表を見る
- 最終確認日: 2026-11-01
- 依存: RULE-007
- ファンの言葉: 捲り、捲る、捲られる
- 項目: entries の `kimarite`（捲り）、`bh`（B）。出走表の回数 `makuri`・`back`
- 測っているもの: `kimarite` の捲りは、そのレースで捲って1・2着になったこと。B は残り半周の時点でバックを先頭で通過したこと
- 区別できないこと: 捲って3着以下だった選手。捲られた側がどのラインだったか（並びと組み合わせて推すしかない）
- 照合: 未照合

## FIELD-004 連対率

- 内容: ファンの言う「連対率」は2着以内の割合。出走表の値と、自分で数えた値の2つがある。
- 種別: データで確かめた事実
- 根拠: 項目の定義（TERM-002）
- 成立期間: 期間の制約なし
- 出典: keirin-platform:docs/data-schema.md@0850049 entries、https://keirin.jp/pc/static/beginner/basics/racecard.html 出走表を見る
- 最終確認日: 2026-11-01
- 依存: TERM-002
- ファンの言葉: 連対率、2連対率、勝率、3連対率
- 項目: entries の `top2_rate`（`win_rate`・`top3_rate`）。または `finish_pos` から自分で数えた率
- 測っているもの: 出走表の値は直近4ヶ月の成績による率。自分で数えた率は、決めた期間の率
- 区別できないこと: どんな相手・どの位置で走ったか（ラインの位置や相手の強さで率は大きく変わる。METH-002、METH-006）
- 照合: 照合済み

## FIELD-005 強さ

- 内容: ファンの言う「強さ」「格」に近い項目は競走得点。
- 種別: データで確かめた事実
- 根拠: 項目の定義（RULE-002）
- 成立期間: 期間の制約なし
- 出典: keirin-platform:docs/score-correction.md@0850049 §1
- 最終確認日: 2026-11-01
- 依存: RULE-002、RULE-003
- ファンの言葉: 強さ、格、点数
- 項目: entries の `score`（競走得点）
- 測っているもの: 直近4ヶ月の1走ごとの点数の平均。点数は番組の平均点と着順で決まる
- 区別できないこと: 級班をまたいだ比較（昇降級の直後は前の級班の点が混ざる）。グレードの高い番組を多く走った選手の水準の違い。窓の走数が少ない選手のばらつき
- 照合: 照合済み
