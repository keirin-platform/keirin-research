# 候補（保留したもの）

判断がつかず保留にした通説や問い。**知識ではないので、結論の根拠に使わない**。
分析を設計するときに、確かめるべき要因の候補として読む（たとえば、ラインの通説を知っていれば、ラインを要因から落とさずに済む）。

テーマごとにファイルを分けている。読むのは、問いに関係するテーマのファイルだけでよい。
